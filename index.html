Student Management System

An end-to-end web application developed for college administration. Features real-time CRUD operations, secure JDBC database transactions, intuitive search & filter, and responsive modern dashboards.

JDBC & MySQL Backend

Employs PreparedStatement to safely execute INSERT, SELECT, UPDATE, and DELETE queries, preventing SQL Injection vulnerabilities.

Java OOP & MVC Architecture

Strictly structured with Model classes (Inheritance with Person & Student), DAO Abstraction, and Servlet Controllers.

Admin Authentication

Session-based authentication allowing authorized administrators to manage records, oversee departments, and monitor key statistics.

Live Search & Multi-Filters

Instant search by Student ID, Student Name, or Register Number, paired with department and academic year multi-filtering.

Real-time Analytics

Visual statistics for total students, active students, department enrollment distribution, and recently registered students.

Responsive Blue & White UI

Designed using modern CSS3 flexbox and grid, beautiful rounded controls, status badges, toast notifications, and modal dialogs.
